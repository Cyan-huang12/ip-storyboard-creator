# 《青崖逆商记》

> 二创副标题（短剧钩子）：**穿越成债奴，我靠一身本事横扫古代商场**
>
> 二创方式：故事大框主线不变（现代能人穿越 → 家破逼债 → 上山搏兽得宝 → 结识贵人挖到第一桶金 → 对抗豪强刁难 → 创合作社改良拓渠 → 建商号带全村致富），**全部人物姓名与身份重做**。
> 风格：热血逆袭 + 商战爽感 + 乡土烟火。
> 载体：竖屏短剧，六幕（六集），每集 3–4 分钟。

## 二、世界观 / 背景设定

大晏王朝末年，青崖村在两山夹一河的坳里，穷得"锅比脸干净"。村里没官府照拂，谁家有粮、谁手里有钱谁说了算——恶东家钱万堂靠一本印子钱账册，把半个村子攥成了自家的长工。山货（药材、菌子、兽皮、蜂蜜）是这地方唯一值钱的东西，可村民不懂行情、不会议价，一筐好货换不来一斗糙米。秦戈带着现代人对"品控、分级、渠道、品牌"的认知掉进这套旧规矩里，等于握着一把村里人看不见的刀。

## 三、人物小传

**秦戈 / 苏晏**（24岁）
现代退役特种侦察兵，在西南丛林执行过搜救，识地形、辨草药、近身格斗是吃饭本事。为救山洪里的孩子被冲下山，醒来成了青崖村被打得吐血的债奴苏晏。性格：冷面热心，越是绝境越平静，习惯先算路再动手。核心欲望：把这一家老小从"人被当账"的处境里捞出来，让青崖村的货能卖上它该值的价。口头禅："先算账，再动手。"小动作：思考时用指节敲三下桌沿，像在数拍子。

**苏阿婆**（62岁）
苏晏的祖母，一家的主心骨。性格：嘴上认命、手里不认输，攥着一枚磨得发亮的铜顶针不肯当。核心欲望：孙子能囫囵活着，别再替这个家去挨打。口头禅："家还在，人就没散。"小动作：急了就攥紧顶针，指节发白。

**钱万堂**（48岁）
青崖村一带的恶东家，放印子钱、开黑秤，一本账册收全村。性格：笑着要命，越客气越阴。核心欲望：把苏家那块靠河的好地连人一起吞了。口头禅："账嘛，好商量。"小动作：说狠话时慢条斯理地拨算盘珠，一颗一颗。

**顾长风**（35岁）
县城醉仙居掌柜，走南闯北的生意人，识货、认理不认脸。性格：精明里带三分侠气，肯为一句"实在话"赌一回。核心欲望：找一条别人抢不走的稳货源。口头禅："货是死的，人是活的。"小动作：验货时爱把东西凑到鼻尖闻一下。

**严崇**（50岁）
严记绸缎庄东家，县里的体面人。性格：面上作揖，背后使绊，最擅长"讲规矩"把人挤出局。核心欲望：不许一个泥腿子搅了本地的行市。口头禅："凡事得讲个体面。"小动作：不悦时慢慢摩挲玉扳指。

**石昭**（22岁）
石家独子，靠他爹在县衙挂名横行的纨绔。性格：蠢横、记仇、爱面子，被打脸就撒泼。核心欲望：谁让他下不来台，他要谁十倍还。口头禅："你可知我爹是谁？"小动作：得意时把玩腰间那块招摇的羊脂玉。

### 第一幕（第1集）：魂穿债奴 · 绝境开场

**场景1 · 青崖村土屋外 · 黄昏（28秒）**
【氛围词】昏黄斜光 / 泥腥味 / 远处犬吠低沉
【画面】镜头压得很低，先给一双沾血的草鞋。四条汉子把一个少年拖出土屋，按在门槛上。为首的钱万堂不动手，坐在一张搬出来的太师椅上，慢慢拨算盘。少年被一脚踹翻，从怀里滚出半块干硬的窝头。苏阿婆扑上去被推开，膝盖磕在石阶上。少年猛地睁眼——瞳孔一缩，眼神从"惊恐"换成了"扫描"：数人、数距离、看四人手上茧子的位置。
【对白】
钱万堂（拨一颗算盘珠）："苏晏啊，你家这利滚利，本金我都替你们记糊涂喽——账嘛，好商量。"（潜台词：地和人，我今天就要定了）
秦戈（撑起半边身子，声音很稳）："好商量。那先把账念清楚，一笔一笔，我听。"（潜台词：你敢乱报，我就当众拆穿你）
【建议时长】28秒
【配乐】压抑低鼓，一声闷响收尾

**场景2 · 土屋内 · 入夜（26秒）**
【氛围词】油灯将灭 / 药味 / 屋外虫声
【画面】秦戈坐在草席上，就着一豆灯光，用炭条在破陶片上划——他把"本金、月息、还了几次、被黑掉几次"排成一列列，指节在桌沿敲三下。阿婆端来半碗掺野菜的稀粥，手抖着递过去。秦戈没喝，先把陶片推到她面前。
【对白】
苏阿婆（攥紧铜顶针）："娃，别算了，认了吧，家还在，人就没散。"
秦戈（抬眼，很轻）："阿婆，账我算过了——他黑了咱们三成。这个家不是要散，是有人想拆了它卖钱。先算账，再动手。"（潜台词：我不是原来那个只会挨打的苏晏了）
【建议时长】26秒
【配乐】孤灯般的单音钢琴，尾音上挑一丝

**场景3 · 青崖村口老槐树下 · 清晨（22秒）**
【氛围词】晨雾未散 / 露水味 / 磨镰刀的沙沙声
【画面】秦戈把那片"账目陶片"立在磨盘上，围拢来看热闹的村民从三两个变成十几个。钱万堂的狗腿子想上前砸，被秦戈一个侧身卸力，反手按在磨盘上，动作干净利落，不见多余。村民一片吸气声。
【对白】
狗腿子（挣扎）："你、你敢动手！"
秦戈（松开手，拍拍他肩）："我没动手，我扶你看清楚——账在这儿，谁黑的钱，写着呢。"（潜台词：今天起，这村的规矩，我要重写一遍）
【建议时长】22秒
【配乐】节奏渐起的弦乐，带一点侠气

**幕末钩子（第1集结尾 · 12秒）**
【画面】秦戈抬头望向云雾锁住的后山，山口一株老松上，钉着一张褪色的告示：**"后山有熊食人，凡入林者，生死自负。"** 他盯着那行字，指节又敲了三下。
【旁白/字幕】"钱是要还的，可这村里，没有一筐货卖得出价——除非，我上那座没人敢上的山。"
【配乐】风声骤停，一记心跳鼓点

### 第二幕（第2集）：入山搏兽 · 悬崖夺芝

**场景4 · 后山林道 · 上午（24秒）**
【氛围词】湿冷阴翳 / 腐叶与兽粪的腥气 / 头顶乌鸦
【画面】秦戈半蹲在泥地，指尖抹过一串爪印，比对深浅——独眼、跛足、右前掌缺半。他折下三根手臂粗的青竹，用兽筋和削尖的石片，就地绑成一支简陋的"竹枪+陷坑"组合，动作是训练出来的肌肉记忆。他往枪尖抹上一层黑褐的草汁。
【对白】
秦戈（自语，低）："断掌，右侧发力弱……那就把你往左边引。"（潜台词：不是打赢它，是让它自己撞上来）
【建议时长】24秒
【配乐】密林里的紧张电子低频

**场景5 · 熊窟前空地 · 正午（30秒）**
【氛围词】阳光刺进林隙 / 血腥味渐浓 / 死一般的静
【画面】断掌熊从阴影里冲出，独眼血红。秦戈不硬接，绕着预设的陷坑走位，把熊一步步逼向左侧发力弱的方向。熊扑空，前掌陷进伪装的坑，秦戈欺身而上，竹枪借熊自身冲力送入要害。人退三步，熊倒地，尘土腾起。秦戈单膝跪地大口喘气，胳膊被划出一道血口子，他却先去看熊倒下的方向——正对着一面湿滑的绝壁。
【对白】
秦戈（喘着，抹掉脸上血）："先算账……再动手。这账，算平了。"（潜台词：命是搏出来的，可这不是终点）
【建议时长】30秒
【配乐】搏斗高潮鼓点，戛然而止归于静

**场景6 · 绝壁石缝 · 午后（26秒）**
【氛围词】崖壁滴水 / 泥土清苦味 / 风在耳边呼啸
【画面】秦戈顺着熊倒下的方向抬头，绝壁石缝里长着一丛巴掌大、纹如云霞的**赤芝**。他撕开衣襟绑住流血的胳膊，赤手贴着湿岩一寸寸往上挪，脚下碎石簌簌落进云雾。指尖终于扣住那丛赤芝根部——他没有急着扯，而是用石片沿根小心起挖，连着一小块附土整个取下。
【对白】
秦戈（贴在崖壁上，气声）："好东西……得连根、带土、囫囵取。伤了根，就不值钱了。"（潜台词：我懂它的价，这就是我要的第一桶金）
【建议时长】26秒
【配乐】悬到极致的无声张力，尾音一声清越铃响

**幕末钩子（第2集结尾 · 10秒）**
【画面】秦戈把赤芝托在掌心，逆光里纹路像活的。远处传来一队马蹄声——县城来的货商车队正经过山脚。
【字幕】"熊皮能换粮，可这株赤芝——得卖给识货的人。"
【配乐】马蹄由远及近，弦乐上扬

### 第三幕（第3集）：识贵人 · 挖到第一桶金

**场景7 · 县城醉仙居 · 门前 · 傍晚（28秒）**
【氛围词】灯笼初上 / 酒香混着炒货香 / 市声嘈杂
【画面】秦戈背着熊皮、怀揣赤芝进城，被门口伙计拦下嫌他寒酸。他不争，把熊皮往台阶一摊——独眼、断掌，一看就是"食人熊"。围观人群哗然。掌柜顾长风闻声出来，先没看熊皮，径直走到秦戈跟前，把赤芝要过去凑到鼻尖闻了一下，又对着灯笼看纹路，眼神一点点亮起来。
【对白】
顾长风（不抬头）："这芝，起根带土，没伤主根——是个懂行的人挖的。小兄弟，开个价。"
秦戈（不虚报）："我不懂县城行情，但我知道它值多少力气。你是识货的，你先开，我看你实不实在。"（潜台词：我赌你讲义气，这一单我们要做长）
【建议时长】28秒
【配乐】市井热闹里透出的一段爽快弦乐

**场景8 · 醉仙居 · 内堂 · 夜（26秒）**
【氛围词】炭炉暖光 / 陈酒醇香 / 算盘轻响
【画面】顾长风推过来一锭银子，又停住，添了一小串铜钱。秦戈没有立刻收，而是把银子推回一半，从怀里掏出那片旧陶片——上面还留着钱万堂的黑账。
【对白】
秦戈："这单我少收你两成。换你一句实在话——县城的山货，眼下是谁说了算的行市？"
顾长风（挑眉，笑）："货是死的，人是活的。你这泥腿子，问的不是价，是路啊。"（潜台词：这小子不是来卖货的，是来入行的）
【建议时长】26秒
【配乐】暖调钢琴叠一缕古琴

**场景9 · 青崖村 · 苏家院 · 深夜（22秒）**
【氛围词】月色清冷 / 灶膛余温 / 狗睡了
【画面】秦戈把一串铜钱和半锭银子放进阿婆掌心，又替她把那枚差点当掉的铜顶针别回衣襟。阿婆的手抖得厉害，攥着钱不敢信。秦戈没提搏熊的伤，把袖子往下拉了拉，盖住血痂。
【对白】
苏阿婆（哽咽）："娃……这钱，够把钱万堂的本金先还上了。"
秦戈（指节敲桌三下）："本金还上，从今往后，是他来求咱们。"（潜台词：我要的不是还债，是翻盘）
【建议时长】22秒
【配乐】温柔钢琴，落一个上扬的问号音

### 第四幕（第4集）：豪强刁难 · 化险为夷 【60% 转折点】

**场景10 · 县城集市 · 白天（24秒）**
【氛围词】烈日晃眼 / 尘土飞扬 / 叫卖声鼎沸
【画面】秦戈带着一小队村民支起山货摊，货按品相分了三档，用竹牌标价——这在旧市集从没人见过。生意刚火，严记绸缎庄东家严崇踱步而来，慢慢摩挲玉扳指，笑着让伙计"帮忙"把秦戈的货牌全撤了，理由是"坏了行市规矩"。石昭在一旁看热闹，故意把一筐赤芝踢翻在泥里。
【对白】
严崇（作揖，笑）："小兄弟，凡事得讲个体面。这标价、分档，坏了大家的行市，撤了吧。"（潜台词：泥腿子也配定价？）
石昭（把玩玉佩）："你可知我爹是谁？这满县的秤，都得听我们的。"
【建议时长】24秒
【配乐】阴测测的低音提琴

**场景11 · 集市中央 · 白天（30秒）——本集/全剧核心反转**
【氛围词】人群围拢 / 汗味与尘土 / 一根针掉地都听得见
【画面】秦戈不吵不闹，当众取出严记刚卖出的一匹"上等"绸缎，又拿出自己一档货，请围观百姓评。他不说严崇作假，只做一件事：把严家绸缎浸进一盆清水——染色脱得满盆浑浊；再验石昭踢翻的赤芝，指出对方根本不识真假。人群哗然，风向骤变。就在此时，一名管税的胥吏被石昭喊来想抓秦戈"扰市"，秦戈却不慌，把那片记着钱万堂黑账、如今又添了严记缺斤短两记录的陶片，双手奉上——
【对白】
秦戈（声不高，字字清）："官爷，我不扰市。我只把两笔账摆出来：一笔是村里被黑的印子钱，一笔是严记短的斤两。您是管税的，短斤缺两——该谁的账？"（潜台词：你想拿我，我就把整条道上的脏都翻给全县看）
胥吏（脸色一变，收起绳索）："这……严东家，此事，怕是要查一查了。"
【建议时长】30秒
【配乐】静默两秒，随后爆发式弦乐，象征攻守易位
【转折点说明】此处为全剧 60% 关键反转：秦戈第一次从"被人拿捏的债奴"逆转为"拿捏豪强的人"，攻守易位。

**场景12 · 严记后院 · 黄昏（22秒）**
【氛围词】残阳如血 / 檀香压不住的火气 / 茶盏磕碎声
【画面】严崇摔了茶盏，玉扳指转得飞快。石昭在一旁跳脚要报复。严崇却抬手压住他，慢慢眯起眼——他不再当街硬来，而是取出一封信，让人连夜送往钱万堂。镜头给到信封上四个字：借刀，杀人。
【对白】
严崇（慢摩玉扳指，冷笑）："当街的账，我认栽。可这条道上的规矩，还没轮到一个泥腿子改。"（潜台词：明的斗不过你，我就借钱万堂的手）
【建议时长】22秒
【配乐】阴谋渐起的密集弦乐

### 第五幕（第5集）：创合作社 · 改良拓渠

**场景13 · 青崖村祠堂 · 白天（28秒）**
【氛围词】老木香 / 尘光里的浮尘 / 众人低声议论
【画面】秦戈把全村人聚到祠堂，地上摊开一张他画的"分工图"：谁采、谁验、谁分档、谁议价、谁运货，一环扣一环。他当众立了三条规矩，写在木板上钉进梁柱：**一、货分三档，档档明价；二、缺斤短两，逐出社；三、赚了钱，先还村里最难的那几家。** 村民从将信将疑到一双双手举起来。
【对白】
秦戈（指节敲木板三下）："一个人搏熊，只能救一家。可咱们把货拧成一股绳，卖的就不是山货——是青崖村这三个字。"（潜台词：我要让"产地"本身变成招牌）
苏阿婆（举起铜顶针，第一个应）："我入！家还在，人就没散——现在，是全村都在。"
【建议时长】28秒
【配乐】渐强的热血弦乐

**场景14 · 合作社作坊 · 连续时间蒙太奇（30秒）**
【氛围词】柴火噼啪 / 药香蜜香交织 / 忙碌的脚步声
【画面】一组快切：竹匾上菌子按大小分格晾晒；蜂蜜过滤后灌进统一的陶罐，封口烙上"青崖"二字；兽皮硝制得柔软整齐；秦戈教妇人把碎药材压成便携的药饼——一个现代人的"标准化、分级、包装、品牌"，被拆成村民一看就懂的土办法。顾长风的货车第一次直接开进了村口装货。
【对白】
顾长风（拍着陶罐上的烙印，笑）："别人卖散货，你卖'字号'。这一步，你比县里那些老东家都走得远。"
秦戈："货是死的，人是活的——路，是走出来的。"（潜台词：把顾掌柜这句话，还给他）
【建议时长】30秒
【配乐】明快跳跃的民乐节奏

**场景15 · 山道 · 夜（意外波动细节 · 26秒）**
【氛围词】火把摇曳 / 松脂焦味 / 山风呼号
【画面】钱万堂受严崇之托，带人半夜堵在运货山道上，要烧秦戈第一批出村的大货。火把逼近，村民慌乱。秦戈却不退，缓缓从怀里掏出一个**旧陶片**——正是第一集那片记账的陶片。他把它高高举起，对着火光。
【对白】
钱万堂（拨算盘珠，狞笑）："烧了你这批货，看你拿什么翻身！"
秦戈（举起陶片，声音很平）："烧啊。可这片上，记着你这些年黑掉全村的每一笔账。货烧了我再挣，这账要是抖到县衙——钱东家，你拿什么还？"（潜台词：同一片陶片，第一集你用它逼我，今天我用它逼你）
【画面收束】钱万堂拨算盘的手，第一次停住了。火把，一支支垂了下去。
【建议时长】26秒
【意外波动说明】首集"逼债的账"（弱势象征）与此处"反制的账"（翻盘筹码）是同一枚道具、含义彻底逆转——对称动作，结果相反。
【配乐】紧绷的鼓点，在算盘停手那一刻骤然收声

### 第六幕（第6集）：建万源商号 · 带全村致富

**场景16 · 县城 · 万源商号挂匾 · 白天（28秒）**
【氛围词】鞭炮硝烟 / 新漆木香 / 满街道贺声
【画面】一块崭新的匾额缓缓升起——**万源商号**。青崖村的货，如今分档、带字号、走稳定的车队，铺进了县城最好的铺面。严崇站在人群边缘，玉扳指转了两圈，终于停下，默默拱了拱手转身离去；石昭想闹事，被自家管事强行拖走。顾长风与秦戈并肩而立。
【对白】
顾长风："当年那个摊开熊皮的泥腿子，如今挂上了自己的字号。"
秦戈（望着匾）："熊皮换的是一顿饭，字号换的是一条道。这条道，够全村一起走。"（潜台词：我要的从来不是一个人翻身）
【建议时长】28秒
【配乐】大气恢弘的弦乐齐奏

**场景17 · 青崖村 · 丰收晒场 · 黄昏（26秒）**
【氛围词】金色余晖 / 新粮的甜香 / 孩童笑闹
【画面】晒场上堆满装好字号的货罐，村民数着分红的铜钱，脸上是踏实的松快。那几户"最难的人家"，第一个领到了钱——正如祠堂木板上钉的第三条规矩。阿婆把那枚一直没舍得当的铜顶针，郑重塞进秦戈手心。
【对白】
苏阿婆（笑中带泪）："这顶针，当年险些当了换你的命。如今，该传给撑起这个家的人了。"
秦戈（握紧顶针，指节敲了敲）："阿婆，家没散，还长大了。"（潜台词：我从一个外来的魂，成了这里真正的人）
【建议时长】26秒
【配乐】温柔而饱满的钢琴与二胡

**场景18 · 后山山口 · 夜 · 结尾余味（20秒）**
【氛围词】星河低垂 / 松涛阵阵 / 万籁俱寂
【画面】秦戈独自登上第一集那处山口，老松上"熊食人"的旧告示早已摘下，钉着的是一块新木牌：**"青崖山货合作社 · 采山有信，分货有档。"** 他抬手，用指节在木牌上轻轻敲了三下——像在数一个新拍子。镜头缓缓推近他的眼睛，倒映着山下万源商号的点点灯火。
【字幕/旁白】"我从山洪里醒来，掉进一个把人当账的地方。如今，账我算清了，山我踏平了——这条道，才刚开个头。"
【结尾特写】他的指节停在木牌上，灯火在瞳孔里明明灭灭。**画面定格。**
【建议时长】20秒
【配乐】主题旋律轻轻收起，留一记悠远余音

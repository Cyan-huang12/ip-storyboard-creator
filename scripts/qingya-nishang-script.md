# 《青崖逆商记》

> 二创副标题（短剧钩子）：**穿越古代欠一身债，我靠一身腿法和脑子横扫商道**
>
> 二创方式：故事大框主线不变（现代能人穿越 → 家破逼债 → 上山搏兽得宝 → 结识贵人挖到第一桶金 → 对抗豪强刁难 → **创办物流货运行·连通四方** → 建字号带全村致富），**全部人物姓名与身份重做**。
> 风格：热血逆袭 + 商战爽感 + 乡土烟火。
> 载体：竖屏短剧，六幕（六集），每集 3–4 分钟。

## 二、世界观 / 背景设定

大晏王朝末年，青崖村困在两山夹一河的坳里，穷得"锅比脸干净"。山货（药材、菌子、兽皮、蜂蜜）是这地方唯一值钱的东西，可山路险、货损重、脚夫黑吃拿卡——十筐好货送出山，能到七筐就算走运，剩下的不是烂在半路，就是被人克扣，好货换不来一斗糙米。这地方没有官府照拂，恶东家钱万堂靠一本印子钱账册，把半个村子攥成自家长工。秦戈带着现代人对"物流"的整套认知——分段接力、中转货栈、标准打包、编号货签、按时送达、损货照赔、路线成网——掉进这套连"准时"两个字都没有的旧脚行规矩里，等于握着一把村里人看不见的刀。

## 三、人物小传

**秦戈 / 苏晏**（24岁）
现代跆拳道冠军，一身凌厉腿法，反应快、心气稳，赛场上最擅长在对手露出破绽的半秒里定胜负。一次回乡遇山洪，为救落水孩子被卷下山，醒来成了青崖村欠着一身债、被打得吐血的农家少年苏晏（良籍平民，只是家里欠了高利贷）。性格：冷面热心，越是绝境越冷静，习惯先算路再出手。核心欲望：把一家老小从"欠债被人拿捏"的处境里捞出来，让青崖村的货能安稳送出山、卖上该值的价。口头禅："先算账，再动手。"小动作：思考时用指节敲三下桌沿，像在数拍子。

**苏阿婆**（62岁）
苏晏的祖母，一家的主心骨。性格：嘴上认命、手里不认输，攥着一枚磨得发亮的铜顶针不肯当。核心欲望：孙子能囫囵活着，别再替这个家去挨打。口头禅："家还在，人就没散。"小动作：急了就攥紧顶针，指节发白。

**钱万堂**（48岁）
青崖村一带的恶东家，放印子钱、开黑秤，一本账册收全村。性格：笑着要命，越客气越阴。核心欲望：把苏家那块靠河的好地连本带利吞下，再逼苏家老小去他庄上做工抵债。口头禅："账嘛，好商量。"小动作：说狠话时慢条斯理地拨算盘珠，一颗一颗。

**顾长风**（35岁）
县城醉仙居掌柜，走南闯北的生意人，识货、认理不认脸。性格：精明里带三分侠气，肯为一句"实在话"赌一回。核心欲望：找一条送得稳、赔得起的货路。口头禅："货是死的，人是活的。"小动作：验货时爱把东西凑到鼻尖闻一下。

**严崇**（50岁）
严记绸缎庄东家，县里的体面人。性格：面上作揖，背后使绊，最擅长"讲规矩"把人挤出局。核心欲望：不许一个泥腿子搅了本地的行市。口头禅："凡事得讲个体面。"小动作：不悦时慢慢摩挲玉扳指。

**石昭**（22岁）
石家独子，靠他爹在县衙挂名横行的纨绔。性格：蠢横、记仇、爱面子，被打脸就撒泼。核心欲望：谁让他下不来台，他要谁十倍还。口头禅："你可知我爹是谁？"小动作：得意时把玩腰间那块招摇的羊脂玉。

## 四、完整故事内容（六集分集梗概）

**总纲**
现代跆拳道冠军秦戈，回乡途中为救山洪里的孩子被卷下山，一魂穿进大晏末年青崖村苏家幼子苏晏的身上——一个替家里扛下高利贷、被恶东家钱万堂打得吐血的良籍穷少年（非奴籍，仍是自由身）。秦戈凭一身凌厉腿法与现代头脑，从被逼债的绝境起步：上山搏杀獠牙野猪王、悬崖夺得千年赤芝，卖给识货的醉仙居掌柜顾长风挖到第一桶金；又在严记东家严崇、石家少爷石昭的明枪暗箭里化险为夷；最终看准"山货送不出、送不准"这个死穴，创办仿现代物流的**万源货运行**，用分段接力、中转货栈、编号货签、准时送达、损货照赔的章程连通四方，带着苏家和全村人从一身负债走向富裕。

**第1集《魂穿负债 · 绝境开场》**
恶东家钱万堂带人堵到苏家门口逼债，把少年苏晏拖出土屋按在门槛上，摆开算盘慢条斯理地"利滚利"。就在这一刻，跆拳道冠军秦戈的魂穿了进来——眼神从惊恐瞬间切成"扫描",开口只要一件事：把账一笔一笔念清楚。当夜他就着油灯用炭条在破陶片上把钱万堂黑掉的三成账目全排了出来；次日又把这片"账目陶片"立到村口磨盘上，一记侧踹加过肩摔撂倒来砸场子的狗腿子，当众立威。抬头望见后山那张"獠牙野猪王伤人，入林生死自负"的旧告示——他知道，救这个家的钱，就在那座没人敢上的山里。

**第2集《入山搏兽 · 悬崖夺芝》**
秦戈进后山，蹲身看蹄印，读出这头独眼野猪王右后腿有旧套伤、发力偏跛，就地用青竹和石片扎出竹枪、挖好陷坑，把猎物往坑道引。野猪直冲而来，他侧身让过第一记冲撞，一记侧踹蹬中它的跛腿逼它重心一歪，野猪前蹄陷坑，他欺身用竹枪借冲力送进要害——小腿被獠牙豁开一道口子，人却先看向野猪倒下的方向：一面湿滑绝壁的石缝里，长着一丛纹如云霞的千年赤芝。他绑住伤腿攀上崖壁，连根带土把赤芝囫囵起下——这就是他要的第一桶金。山脚下，县城货商的车队正好路过。

**第3集《识贵人 · 挖到第一桶金》**
秦戈拖着比人还壮的獠牙野猪、怀揣赤芝进城，被醉仙居伙计嫌寒酸拦下。掌柜顾长风闻讯出来，一眼看出这赤芝"起根带土、没伤主根，是懂行人挖的"，痛快收货。秦戈却不虚报价，反而少收两成，只换顾长风一句实在话——顾长风点破：这一带最难的不是买货，是送货，"山里好东西多，十筐到我手上只剩七筐，还常误期"。秦戈把这句"送货难"牢牢记下。回到村里，他把钱还上钱万堂的本金，替阿婆别回那枚差点当掉的铜顶针：从今往后，不是他求人，是别人来求他。

**第4集《豪强刁难 · 化险为夷》【全剧60%转折】**
秦戈带村民把山货分三档、竹牌标价摆上县城集市，生意火爆，却撞上严记东家严崇——他笑着以"坏了行市规矩"为由撤掉货牌，纨绔石昭当众踹翻一筐赤芝。秦戈不吵不闹，当众把严记刚卖的"上等"绸缎浸进清水，染色脱得满盆浑浊；石昭喊来管税胥吏要拿他"扰市",他反手奉上那片记着钱万堂黑账、又添了严记缺斤短两的陶片，一句"短斤缺两，该谁的账"当场把攻守易位——胥吏反过来要查严记。这是秦戈第一次从"被拿捏的欠债少年"变成"拿捏豪强的人"。严崇当街认栽，暗里却修书一封送往钱万堂：借刀杀人。

**第5集《创货运行 · 连通四方》**
秦戈在祠堂聚齐全村，摊开一张从青崖村到县城、中途设两座中转货栈的"路线图",立下三条钉进梁柱的规矩：一筐一签、编号造册，丢一筐赔十筐；脚夫车队按站接力，中途克扣者逐出行；赚了钱先补村里最难的几家。阿婆举着铜顶针第一个入伙。货栈立起、货签挂上、路线连成网、车队天不亮就发运日中即到——顾长风的商队头一回不必进山，只在县城货栈点签签收。这天深夜，受严崇之托的钱万堂带人堵在山道上，要烧掉货运行第一趟满载的车队。火把逼近，秦戈却掏出第一集那片记账陶片高高举起：货烧了他再挣，可这账要是抖到县衙——钱万堂拨算盘的手，第一次停住了。

**第6集《建万源货运行 · 带全村致富》**
崭新的"万源货运行"匾额升起，青崖村的货靠分段接力、编号货签、准时送达，车队直接铺进县城最好的铺面卸货。严崇默默拱手离场，石昭被自家管事拖走，顾长风与秦戈并肩而立。青崖村晒场上，村民有的当脚夫、有的看货栈、有的跟车队，数着分红的铜钱，那几户"最难的人家"头一个领到钱。阿婆把一直没舍得当的铜顶针郑重塞进秦戈手心。夜里，秦戈独自登上后山山口——老松上"野猪伤人"的旧告示早已换成"万源货运行·青崖站：货签为凭，准时必达，损货照赔"。他指节在木牌上敲了三下，瞳孔里倒映着山下万源货运行的点点灯火：账算清了，山踏平了，货路铺通了，这条道才刚开个头。

### 第一幕（第1集）：魂穿负债 · 绝境开场

**场景1 · 青崖村土屋外 · 黄昏（28秒）**
【氛围词】昏黄斜光 / 泥腥味 / 远处犬吠低沉
【画面】镜头压得很低，先给一双沾血的草鞋。四条汉子把一个少年拖出土屋，按在门槛上。为首的钱万堂不动手，坐在一张搬出来的太师椅上，慢慢拨算盘。少年被一脚踹翻，从怀里滚出半块干硬的窝头。苏阿婆扑上去被推开，膝盖磕在石阶上。少年猛地睁眼——瞳孔一缩，眼神从"惊恐"换成了"扫描"：数人、数距离、看四人手上茧子的位置。
【对白】
钱万堂（拨一颗算盘珠）："苏晏啊，你家这利滚利，本金我都替你们记糊涂喽——账嘛，好商量。"（潜台词：地和人，我今天就要定了）
秦戈（撑起半边身子，声音很稳）："好商量。那先把账念清楚，一笔一笔，我听。"（潜台词：你敢乱报，我就当众拆穿你）
【建议时长】28秒
【配乐】压抑低鼓，一声闷响收尾

**场景2 · 土屋内 · 入夜（26秒）**
【氛围词】油灯将灭 / 药味 / 屋外虫声
【画面】秦戈坐在草席上，就着一豆灯光，用炭条在破陶片上划——他把"本金、月息、还了几次、被黑掉几次"排成一列列，指节在桌沿敲三下。阿婆端来半碗掺野菜的稀粥，手抖着递过去。秦戈没喝，先把陶片推到她面前。
【对白】
苏阿婆（攥紧铜顶针）："娃，别算了，认了吧，家还在，人就没散。"
秦戈（抬眼，很轻）："阿婆，账我算过了——他黑了咱们三成。这个家不是要散，是有人想拆了它卖钱。先算账，再动手。"（潜台词：我不是原来那个只会挨打的苏晏了）
【建议时长】26秒
【配乐】孤灯般的单音钢琴，尾音上挑一丝

**场景3 · 青崖村口老槐树下 · 清晨（22秒）**
【氛围词】晨雾未散 / 露水味 / 磨镰刀的沙沙声
【画面】秦戈把那片"账目陶片"立在磨盘上，围拢来看热闹的村民从三两个变成十几个。钱万堂的狗腿子想上前砸，秦戈一记利落侧踹逼退他，再顺势一个过肩摔把人按在磨盘上——腿法干净，不见多余。村民一片吸气声。
【对白】
狗腿子（挣扎）："你、你敢动手！"
秦戈（松开手，拍拍他肩）："我没动手，我扶你看清楚——账在这儿，谁黑的钱，写着呢。"（潜台词：今天起，这村的规矩，我要重写一遍）
【建议时长】22秒
【配乐】节奏渐起的弦乐，带一点侠气

**幕末钩子（第1集结尾 · 12秒）**
【画面】秦戈抬头望向云雾锁住的后山，山口一株老松上，钉着一张褪色的告示：**"后山有獠牙野猪王伤人，凡入林者，生死自负。"** 他盯着那行字，指节又敲了三下。
【旁白/字幕】"钱是要还的，可这村里，没有一筐货卖得出价——除非，我上那座没人敢上的山。"
【配乐】风声骤停，一记心跳鼓点

### 第二幕（第2集）：入山搏兽 · 悬崖夺芝

**场景4 · 后山林道 · 上午（24秒）**
【氛围词】湿冷阴翳 / 腐叶与兽粪的腥气 / 头顶乌鸦
【画面】秦戈半蹲在泥地，指尖抹过一串蹄印，比对深浅——独眼、右后腿带旧套伤、走起来发力偏跛。他折下三根手臂粗的青竹，用兽筋和削尖的石片，就地绑成一支简陋的"竹枪+陷坑"组合，手上是赛场练出来的那股稳劲。他往枪尖抹上一层黑褐的草汁。
【对白】
秦戈（自语，低）："跛腿，右后使不上力……赛场上找破绽的本事，用在这头畜生身上，一样。把你往那条坑道引。"（潜台词：不是硬拼，是让它自己撞上来）
【建议时长】24秒
【配乐】密林里的紧张电子低频

**场景5 · 野猪林窝前空地 · 正午（30秒）**
【氛围词】阳光刺进林隙 / 血腥味渐浓 / 死一般的静
【画面】獠牙野猪王从林窝里直冲出来，獠牙半尺、独眼血红，一路撞断挡道的灌木。秦戈不硬接，贴着预设的陷坑走位，侧身让过第一记冲撞，落地借势，一记侧踹重重蹬在它跛着的右后腿上，逼它重心一歪。野猪收势不住，前蹄陷进伪装的陷坑，秦戈欺身而上，竹枪借野猪自身的冲力送进咽喉要害。人退三步，野猪轰然倒地，尘土腾起。秦戈单膝跪地大口喘气，小腿被獠牙豁开一道血口子，他却先去看野猪倒下的方向——正对着一面湿滑的绝壁。
【对白】
秦戈（喘着，抹掉脸上血）："先算账……再动手。这账，算平了。"（潜台词：命是搏出来的，可这不是终点）

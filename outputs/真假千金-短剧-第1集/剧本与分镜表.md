# 《真假千金》短剧 · 第 1 集《我死之后，睁眼是十岁》

> **二创方向**：倒叙钩子开局（时间线手术）
> **形式 / 时长**：竖屏短剧首集，约 60 秒
> **风格**：重生打脸爽文
> **改编依据**：`outlines/真假千金-故事大纲.md`（卷一·破茧 第一、二章）
> **本集钩子逻辑**：冷开场直接放前世惨死+听见掉包真相 → 白光重生回到 10 岁被踹的泥地 → 集尾埋"三天后当街举告"的钩，逼观众追第 2 集。

## 一、人物小传

**阿苔（10 岁 / 前世 15 岁）**
镇南侯府真嫡女，出生即被抱错，在青州唐家村被当牲口使唤养大。前世受虐至 15 岁惨死，死后听见掉包真相；重生带回 15 年人生阅历 + 一脑子现代农事知识（种子、堆肥、曲辕犁、水车、嫁接）。性格：不哭不闹、隐忍到发冷，认准的事一步都不退。标志：受伤也挺直的脊背；下决心时垂眸再抬眼，眼底比年龄冷十岁。核心欲望——这一世要让害她的人跪着听她说话。

**唐氏（40 岁）**
阿苔前世养母，当年偷换婴儿的元凶。性格：又贪又狠，得意时爱冷笑着说漏嘴。标志动作：叉腰、用下巴指人。核心欲望——把偷来的富贵一直捂在手里。

**唐大牛（42 岁）**
唐氏之夫，动辄对阿苔拳打脚踢的施暴者。标志：骂骂咧咧、摔门。

## 二、世界观

架空古代王朝。京城有镇南侯府这样的顶级门第，十五年前一场抱错，把真嫡女丢进了青州最穷的唐家村。侯府车队每逢清明经苍梧山进京——这是乡下与侯府之间唯一会短暂交汇的缝隙，也是阿苔重生后要抓住的第一根绳子。

## 三、剧本正文（4 场景 / 共 60 秒）

### 场景 1 · 唐家破屋外 · 雨夜（前世·15 秒）
**氛围词**：暴雨/泥腥味/冷得刺骨/远处一声闷雷
**画面动作**：瓢泼雨夜，枯瘦的少女阿苔倒在泥地里，一只冻裂的手无力摊开，指尖抽搐一下就松了。唐氏蹲下来，居高临下地俯视，嘴角冷笑。阿苔涣散的瞳孔里映着雨，一滴泪滚进泥水。
**对白**：
- 唐氏（俯身，冷笑）：“侯府的嫡女？就你这副烂命，也配。”〔潜台词：说漏了掉包的真相，却当她听不懂〕
- 字幕：**这是我第一次死。我听见了那句本不该听见的话。**
**配乐**：暴雨声渐强 + 一根低沉大提琴长音，戛然而止

### 场景 2 · 同一片泥地 · 重生瞬间（15 秒）
**氛围词**：白光炸开/耳鸣/闷响/骤然安静
**画面动作**：一道白光与闷响，画面剧烈一晃。阿苔猛地睁眼——还是这双眼，眼神却活了过来。她躺在同一片泥地上，却成了十岁的小小身板，额角渗血。脑中轰然涌进画面：种子破土、曲辕犁翻地、水车转动。她抬手摸额头的血，怔住。
**对白**：
- 唐大牛（画外，骂声）：“死丫头躺那儿装什么死！还不去挑水！”
- 字幕：**重活一次。回到十岁。我记得往后十五年的每一件事。**
**配乐**：无声张力 → 一记心跳鼓点砸下

### 场景 3 · 唐家破院（12 秒）
**氛围词**：湿冷/柴烟味/院里一只湿鸡
**画面动作**：阿苔默默爬起，拎起比她还高的水桶去打水，动作麻木而顺从。唐氏叉腰审视她半晌，见没什么异样，撇嘴转身。唐大牛摔门骂咧着出去。镜头收到阿苔脸上——她垂着眼，眼底那点冷静，和这具十岁的身子对不上。
**对白**：
- 唐氏（打量，狐疑）：“摔一下倒老实了。”〔潜台词：只当踹狠了，没察觉她换了个人〕
**配乐**：极简单音钢琴，克制

### 场景 4 · 唐家灶房 · 深夜（18 秒·60% 转折点 + 结尾钩）
**氛围词**：灶膛火光/灰烬味/全家鼾声/火苗噼啪
**画面动作**：深夜，全家熟睡。阿苔独自蹲在灶膛前，就着火光，用一截炭在灶灰上一笔一笔写字——“牵牛花”“襁褓”“换”。火光跳动，映着她过分平静的小脸。她写完，抬眼直视前方，眼神狠得不像孩子。她起身，一口吹灭火折。
**对白**：
- 阿苔（轻声，一字一顿）：“三天后，侯府的马车，会经过村口。”〔潜台词：前世她跪着挨打，这一世她要跪着举告、站着回府〕
- 字幕（黑屏）：**这一次，轮到你们跪着，听我说话。**
- 字幕：**未完待续**
**配乐**：低频铺底渐起 → 收尾一记闷鼓，黑屏

**结尾余味**：最后一个画面停在被吹灭的火折，一缕青烟在黑暗里笔直上升——像她挺直的、再也不肯弯的脊背。

## 五、自检清单

**镜号与时间段**
- [x] 镜号格式「分镜号-镜头号」，无小数
- [x] 每 Batch 累计 ≤15 秒（场景 4 拆为 Batch1 12-15 + Batch2 0-3）
- [x] 满 15 秒后下个 Batch 从 0 重新计时
- [x] 分镜时间段无 ≥15 的数值

**运镜多样性**
- [x] 运镜 9 种（≥6）：慢推/固定/慢移/手持晃动/快速摇移/跟拍/平移/慢拉/低角度固定

**剧本完整性**
- [x] 3 个角色均有 ≥30 字小传（背景/性格/欲望/标志）
- [x] 有世界观设定
- [x] 每个场景 ≥2 个感官氛围词

## 六、写入飞书多维表格（可选）

本环境无 `lark-cli` / 飞书凭证，未自动写入。你在 OpenClaw + lark-cli 环境下，可用本目录同附的两个文件一键写入：

```bash
# 1) 建表
lark-cli base +base-create --name '真假千金短剧——第1集分镜表'
# 2) 建字段（app_token 用上一步返回值）
lark-cli base +table-create --base-token <token> --name '分镜表' --fields @fields_21.json
# 3) 批量写入（table-id 用上一步返回值）
lark-cli base +record-batch-create --base-token <token> --table-id <tableId> --json @batch_data.json
```

# 《青崖逆商记》

> 二创副标题（短剧钩子）：**穿越古代欠一身债，我靠一双眼睛和一颗生意脑子，趟出一条没人敢走的路**
>
> 二创方式：故事大框主线不变（现代能人穿越 → 家破逼债 → 上山搏兽得宝 → 结识贵人挖到第一桶金 → 看清市场三大死结 → 商战立信 → 创办物流货运行 → 建字号带全村致富），**全部人物姓名与身份重做**。
> 风格：热血逆袭 + 商战爽感 + 乡土烟火。
> 载体：竖屏短剧，六幕（六集），每集 3–4 分钟。

## 二、世界观 / 背景设定

大晏王朝末年，青崖村困在两山夹一河的坳里。山货（药材、菌子、兽皮、蜂蜜）是这地方唯一值钱的东西，可山路险、货损重、脚夫黑吃拿卡——十筐好货送出山，能到七筐就算走运，剩下的不是烂在半路，就是被沿途克扣；外乡货商收了货又常常赖账，村民卖一次亏一次，索性宁可让好货烂在手里。这地方没有官府照拂，恶东家钱万堂靠一手"利滚利"的债契——把利钱记回本金、逼人典卖祖田——半个村子的好地，都快姓了钱。秦戈带着现代人对"物流"的整套认知——分段接力、中转货栈、编号货签、按时送达、损货照赔、路线成网——掉进这套连"准时""托付"都不存在的旧脚行规矩里，等于握着一把村里人看不见的刀。但他很快明白：**在古代白手起家开一条货路，光有想法不够，得先凑齐人、钱、信任、路线、客户、车马这六样，缺一不成。**

## 三、人物小传

**秦戈 / 苏晏**（24岁）
现代跆拳道冠军，退役后回乡，一身好体能、反应快、抗击打。可穿越后附在被高利贷压垮、刚挨过打的苏晏身上，力气大打折扣——他真正的利器从来不是拳脚，而是**一双看门道的眼睛和一颗做生意的脑子**：会观察、算得清、能从别人习以为常的乱象里挑出破绽。搏野猪靠的是读蹄印、看习性、借地形下套，不是硬拼；制服壮汉靠的是借力，不是蛮劲。性格：冷面热心，越是绝境越冷静，遇事先看清再出手。核心欲望：把一家老小从"欠债被人拿捏"里捞出来，让青崖村的货能安稳送出山、卖上该值的价。口头禅："先算账，再动手。"小动作：想通一件大事时，会用指节在桌沿轻敲三下。

**苏阿婆**（62岁）
苏晏的祖母，一家的主心骨。性格：嘴上认命、手里不认输，攥着一枚磨得发亮的铜顶针不肯当。核心欲望：孙子能囫囵活着，别再替这个家去挨打。口头禅："家还在，人就没散。"小动作：急了就攥紧顶针，指节发白。

**钱万堂**（48岁）
青崖村一带的恶东家，放印子钱、写重利债契、开黑秤。性格：笑着要命，越客气越阴。核心欲望：把苏家那块靠河的好地连本带利吞下——他早知后山有值钱的东西，却用一纸"野猪伤人"的告示，把采药人一个个诓进去送死，自己坐收其利。口头禅："账嘛，好商量。"小动作：说狠话时慢条斯理地拨算盘珠，一颗一颗。

**顾长风**（35岁）
县城醉仙居掌柜，走南闯北的行商，识货、认理不认脸。性格：精明里带三分侠气，肯为一句"实在话"赌一回。核心欲望：找一条送得稳、赔得起、敢让人托付的货路。口头禅："货是死的，人是活的。"小动作：验货时爱把东西凑到鼻尖闻一下。

**严崇**（50岁）
严记绸缎庄东家，县里的体面人。性格：面上作揖，背后使绊，最擅长"讲规矩"把人挤出局。核心欲望：不许一个泥腿子搅了本地的行市。口头禅："凡事得讲个体面。"小动作：不悦时慢慢摩挲玉扳指。

**石昭**（22岁）
石家独子，靠他爹在县衙挂名横行的纨绔。性格：蠢横、记仇、爱面子，被打脸就撒泼。核心欲望：谁让他下不来台，他要谁十倍还。口头禅："你可知我爹是谁？"小动作：得意时把玩腰间那块招摇的羊脂玉。

## 四、完整故事内容（六集分集梗概）

**总纲**
现代跆拳道冠军秦戈，为救山洪里的孩子被卷下山，一魂穿进大晏末年青崖村苏家幼子苏晏的身上——一个替家里扛下高利贷、被恶东家钱万堂逼着典卖祖田的良籍穷少年。秦戈的过人之处不在拳脚，而在一双看门道的眼睛和一颗做生意的脑子。他从被逼债的绝境起步：上山靠观察与陷阱搏杀獠牙野猪王、悬崖夺得百年赤芝，卖给识货的醉仙居掌柜顾长风挖到第一桶金；顾长风点破这一带"缺的不是车，是一条敢让人托付的路"，秦戈就此看清市场的三大死结——村民不敢卖、商户敢压价、货商敢赖账；他在与严记东家严崇、石家少爷石昭的商战中当众立信、破掉死结，赢得口碑与第一个大客户；再凑齐人、钱、信任、路线、客户、车马这六样，创办仿现代物流的**万源货运行**，用编号货签、按站接力、准时送达、损货照赔的章程连通四方，带着苏家和全村从一身负债走向富裕。

**第1集《魂穿负债 · 绝境开场》**
恶东家钱万堂带人上门，不是抓人，而是拍出一纸"利滚利"的债契，要收走苏家靠河的祖田抵债。少年苏晏扑上去夺地契被推倒撞出血——就在这一刻，跆拳道冠军秦戈的魂穿了进来，胸口剧痛、脑中闪过原主挨打的记忆，他扶着门框站直，眼神从求饶变成看门道。当夜他抽一片竹篾、用炭条刻下账目，算清钱万堂"把利钱记回本金、再拿本金生利"的套路；次日在村口把这片账目竹片立上磨盘，一个借力摔撂倒来砸场子的狗腿子，当众揭穿黑账。归拢散落的债契时，他发现好几张欠契出自同一种人家——男人这两年进后山采药再没回来，债主全是钱万堂，事由是"借银置采药家什"。钱万堂的算盘他一眼看穿：药采回来利归他，人死了债转给爹娘妻儿照样归他。后山这笔钱，钱万堂想要，却舍不得拿自己一条命去换，只敢拿旁人的命去填。**那我去拿。**

**第2集《入山搏兽 · 悬崖夺芝》**
秦戈进后山，蹲身读蹄印，看出这头独眼野猪王右后腿有旧伤、发力偏跛，且每天走同一条觅食死道。他不硬碰，折竹削签、在必经窄道挖坑铺枝，把逃路一条条堵死，只留一个方向。野猪最怕火，他用火把一晃逼它直冲——野猪认死理、只会闷头撞，一头栽进陷坑，他借它挣扎的力道送上竹枪拿下，小腿被獠牙豁开一道口子。人却先看向野猪倒下的方向：一面湿滑绝壁的石缝里，长着一丛纹如云霞的百年赤芝。他绑住伤腿攀上崖壁，连根带土把赤芝囫囵起下——这就是他要的第一桶金。山脚下，县城货商的车队正好路过。

**第3集《识贵人 · 看清三死结》**
秦戈拖着比人还壮的獠牙野猪、怀揣赤芝进城，醉仙居掌柜顾长风一眼看出这赤芝"起根带土、没伤主根，是懂行人挖的"，痛快收货。秦戈不虚报价、反少收两成，只换顾长风一句实在话——顾长风正色点破："缺的从来不是车马，是一条敢让人把货交到你手上的路。"回村路上、集市当口，秦戈把三幕看进眼里：村民宁可让好菌子烂在墙角也不肯去卖；商户当着老农的面把价压掉一半；外乡货商收了货撂下一句"回头结"就再不露面。**村民不敢卖、商户敢压价、货商敢赖账——这三个死结不解开，什么车马路线都是空的。**

**第4集《商战立信 · 化险为夷》【全剧60%转折】**
秦戈带村民把山货分三档、竹牌明价摆上县城集市，生意火爆，却撞上严记东家严崇——他笑着以"坏了行市规矩"为由撤牌，纨绔石昭当众踹翻一筐赤芝。秦戈不吵不闹，当众把严记刚卖的"上等"绸缎浸进清水、染色脱得满盆浑浊；石昭喊来胥吏要拿他"扰市",他反手奉上那片刻着钱万堂黑账、又添了严记缺斤短两的竹片，一句"短斤缺两，该谁的账"逼得胥吏反查严记。这一战，他当众破了三死结里的头一个——**取信**：让村民信"跟着他卖不吃亏"、让顾长风信"这条路托得住"。人群外，顾长风挤到他身边低声一句："第一批货，我托给你。"这是秦戈第一次从被拿捏的欠债少年，变成拿捏豪强的人。严崇当街认栽，暗里却修书一封，送往钱万堂：借刀杀人。

**第5集《六样凑齐 · 创货运行》**
秦戈在祠堂摊开跑了半月画成的路线图：青崖村—两座中转货栈—县城，另一条通邻镇。他把家底摊给全村看——**钱**，用赤芝和卖货攒下的本；**车**，置办三挂骡车、修通两处塌方山道；**路**，两条勘定的固定路线；**客**，顾长风头一个托付、还带来两家相熟商户；就差最后一样——**人**。他立下三条钉进梁柱的规矩：一筐一签、编号造册，丢一筐赔十筐；按站接力，中途克扣者逐出行；赚了钱先补村里最难的几家。阿婆举着铜顶针第一个入伙。货栈立起、货签挂上、骡车按站接力、天不亮发运日中即到。这天深夜，受严崇之托的钱万堂带人堵在山道上，要烧掉货运行第一趟满载的车队。火把逼近，秦戈却掏出第一集那片账目竹片高高举起：货烧了他再挣，可这片上刻着钱万堂黑掉全村的每一笔账，一旦抖到县衙——钱万堂拨算盘的手，第一次停住了。

**第6集《建万源货运行 · 带全村致富》**
崭新的"万源货运行"匾额升起，青崖村的货靠分段接力、编号货签、准时送达，车队直接铺进县城最好的铺面卸货。严崇默默拱手离场，石昭被自家管事拖走，顾长风与秦戈并肩而立。青崖村晒场上，村民有的当脚夫、有的看货栈、有的赶骡车，数着分红的铜钱，那几户"最难的人家"头一个领到钱。阿婆把一直没舍得当的铜顶针郑重塞进秦戈手心。夜里，秦戈独自登上后山山口——老松上"野猪伤人"的旧告示早已换成"万源货运行·青崖站：货签为凭，准时必达，损货照赔"。他抬手，用指节在木牌上轻轻敲了三下，瞳孔里倒映着山下万源货运行的点点灯火：账算清了，山踏平了，货路铺通了，这条道才刚开个头。

### 第一幕（第1集）：魂穿负债 · 绝境开场

**场景1 · 青崖村苏家 · 院门 · 黄昏（28秒）**
【氛围词】昏黄斜光 / 泥腥味 / 远处犬吠低沉
【画面】镜头压得很低：门槛上一摊没干的血、半块摔在地上的窝头。钱万堂坐在被搬进院里的太师椅上，慢条斯理拨算盘；一个狗腿子把一纸债契拍在石桌上，另一个正往怀里卷苏家那张靠河祖田的地契。少年苏晏扑上去要夺地契，被一把推开，肩背撞在门框上，闷哼一声，额角磕出血。就在这一下——他猛地睁眼，胸口一阵剧痛，脑中闪过原主今早被按在地上拳脚相加、吐血求饶的画面。他撑着门框，一寸寸站直，眼神变了：不再是求饶，而是慢慢扫过四人的站位、手上的茧子，和那张正被卷走的地契。
【对白】
- 钱万堂（拨一颗算盘珠，笑）："苏家的地，抵了这些年的利钱，也不算亏。地契我先收着——账嘛，好商量。"（潜台词：这块靠河的好地，我惦记很久了）
- 秦戈（撑着门框，声音发哑却稳）："地契，放下。账没念清之前，谁也别想动我家的田。"（潜台词：我不是那个只会挨打求饶的苏晏了）
【建议时长】28秒
【配乐】压抑低鼓，一声闷响收尾

**场景2 · 苏家土屋内 · 入夜（26秒）**
【氛围词】油灯将灭 / 草药苦味 / 屋外虫声
【画面】秦戈就着一豆灯光，从墙角废柴里抽出一片竹篾，用灶膛掏出的炭条在上面一道道刻记：借了多少、契上写多少、还了几回。阿婆端来半碗掺野菜的稀粥，手抖着递过来。秦戈没喝，先把竹片推到她面前——想通了什么，指节在桌沿轻敲了三下。
【对白】
- 苏阿婆（攥紧铜顶针）："娃，别算了，认了吧，家还在，人就没散。"
- 秦戈（抬眼，很轻）："阿婆，我算过了——本金二两，借据写五两；还了三回，他每回都把利钱记回本金，再拿本金生利。这不是咱还不清，是他从没想让咱还清。"（潜台词：他要的不是钱，是咱家那块地）
【建议时长】26秒
【配乐】孤灯般的单音钢琴，尾音上挑一丝

**场景3 · 青崖村口 · 老槐树下 · 清晨（22秒）**
【氛围词】晨雾未散 / 露水味 / 磨镰刀的沙沙声
【画面】秦戈把那片刻着账的竹片立在磨盘上，围拢来看热闹的村民从三两个变成十几个。钱万堂的狗腿子骂骂咧咧冲上来要砸——秦戈不硬接，侧身让过扑势，顺着对方冲来的力道一带一送，壮汉自己栽进磨盘边的草垛。动作全是借力，不见蛮劲。村民一片吸气声。
【对白】
- 狗腿子（从草垛里爬起）："你、你敢还手！"
- 秦戈（拍拍手上的灰）："我没还手，是你自己冲太急。账在这儿——他怎么把利钱记回本金的，一道一道，刻着呢。"（潜台词：从今天起，这村的账，得我说了算）
【建议时长】22秒
【配乐】节奏渐起的弦乐，带一点侠气

**幕末钩子（第1集结尾 · 14秒）**
【氛围词】暮色四合 / 纸张受潮的霉味 / 山风起

## 七、本轮改编要点（应用户意见修订）

**结构（更扎实的创业铺垫）**
1. 第3集结尾新增顾长风点题——"缺的不是车，是一条敢让人托付的路"——并让秦戈当场看清**三大死结**（村民不敢卖 / 商户敢压价 / 货商敢赖账），作为第3→5集的过渡。
2. 第4集商战重新定位为"**立信**"：破掉"商户敢压价"死结、赢得村民信任与顾长风这个第一大客户的托付。
3. 第5集创业**明确凑齐六样**：人、钱、信任、路线、客户、车马——不再是"有想法就成"。

**古代逻辑**
4. 逼债不再"拖走人"：改为钱万堂拍出**利滚利债契、逼收苏家靠河祖田**（苏晏是良籍平民，恶霸不能公开绑人）。
5. 记账套路古代化：不提"黑了三成"，改为"**本金二两、借据写五两；利钱记回本金再生利**"的驴打滚重利。
6. 记账道具由陶片改为**刻账竹片**（更符合古代民间，视觉一致，且贯穿首尾作反转道具）。
7. 宝物由"千年赤芝"降格为"**百年赤芝**（少见野山灵芝）",去玄幻化，回归商业逆袭内核。

**人设与打斗**
8. 搏野猪去"跆拳道化"：改为**读蹄印、判伤腿、看习性、用火惊、借地形陷阱**取胜，秦戈明说"靠的是脑子不是拳头"。
9. 制服狗腿子改为**借力摔**（解释刚挨打的人为何能撂倒壮汉）。
10. 收敛"全能"人设：突出**现代体育冠军 + 极强观察力 + 商业头脑**，弱化野外求生/物流/商战样样精通的观感。
11. "指节敲三下"由全篇滥用收敛为**仅开篇（场景2）与结局（场景18）各一次**的首尾呼应。

**第一集细节**
12. 秦戈魂穿去"系统扫描"感：加入**胸口剧痛 + 原主挨打记忆闪回 + 眼神由求饶转看门道**的身体记忆冲突。
13. 集尾钩由"死亡名单"改为**"采药人家属的欠契"**（钱万堂借银给采药人买家什，人死债转家人）——名单夹在公开债契里不合反派逻辑，欠契本就是债契的一部分，出现自然，且"采回来利归他、人死了债照样归他"更符合商人算计。
14. 反派动机升级：秦戈旁白由"他不敢拿的钱"改为**"想要却舍不得拿命换、只敢拿旁人的命去填"**，不降反派智商。
15. 删去"指节敲三下"的编剧视角说明（原场景2/场景18/小传里的呼应注释），让动作自然出现，不写作者注。
